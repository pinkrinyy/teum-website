틈새살이 게임 실행 방법

1. 압축을 푼 폴더 안의 index.html 을 더블클릭해서 크롬으로 엽니다.
   (크롬 권장, 인터넷이 연결돼 있어야 글꼴이 디자인대로 나옵니다)
2. 4자리 코드를 입력합니다.

   [실제 코드]            합류(내가 임차인)  들임(내가 임대인)  찾음(같이 새집)
   금전형 강은지/강지혁        7391              7392              7393
   규칙형 서은민/서민호        2647              2648              2649
   감정형 김정희/김석홍        9522              9521              9520

   [테스트용 코드]  금전 0001 / 0011 / 0111,  규칙 0002 / 0022 / 0222,  감정 0003 / 0033 / 0333

3. 성별·이름 → 메이트 매칭 → 합의서 서명 → 게임 순서로 진행됩니다.
   (테스트용: 코드 입력 후 Ctrl + Shift + S 를 누르면 합의서까지 건너뛰고 바로 게임으로 갑니다)

4. 게임 방법
   - 화면을 눌러 캐릭터를 이동하고, 빨간 ! 핀이나 물건을 눌러 미션을 시작합니다.
   - 미션을 시작하면 오른쪽에서 '틈' 앱(핸드폰)이 나오고, 핸드폰 왼쪽 안내 말풍선이
     눌러야 할 버튼과 다음 할 일을 알려 줍니다. 미션이 끝나면 핸드폰은 다시 들어갑니다.
   - 왼쪽 위 '오늘의 미션'과 '힌트'가 다음에 할 일을 알려 줍니다.
   - 금전형: 냉장고·빨래 미션은 순서 상관없이 진행합니다.
   - 규칙형: 부엌 싱크대(설거지 규칙 만들기)·쓰레기통(분리수거 체크)·식탁 위 고지서(생활비 정산)를
     순서 상관없이 진행합니다.
   - 감정형: 거실 TV(채팅으로 안건 올리기)·책상 위(피드백)를 진행합니다.
   - 유형마다 방은 하나입니다 (금전형 부엌 / 규칙형 부엌 / 감정형 거실).
   - 모든 유형: 미션 두 개를 마치면 화면 오른쪽 위에 메이트가 올린 '새 안건' 알림이 옵니다.
     알림을 누르면 틈 앱에서 안건을 읽고 AI 물어보기로 의견을 맞춘 뒤 엔딩으로 갑니다.
   - 메이트 머리 위 말풍선(또는 메이트)을 누르면 지금 상황에 맞는 대화를 나눌 수 있습니다.
   - 대화창이 떠 있을 때는 게임 화면 아무 곳이나 누르거나 Enter 로 넘깁니다.
   - 미션을 모두 마치고 후기를 남기면 같은 설정으로 다른 유형을 이어서 해 볼 수 있습니다.

5. 좌표 수정 도구 (제작용 - 관람객에게는 필요 없음)
   - 같은 폴더의 좌표수정도구.html 을 크롬으로 엽니다. 게임 안에는 좌표 수정 기능이 없습니다.
   - 위쪽 탭: [🛠 게임 좌표] 오브젝트·핀·도착 지점 위치 / [⌗ 충돌 영역] 가구 바닥 다각형 /
     [🟩 이동 가능 영역] 캐릭터가 걸을 수 있는 바닥 칠하기. 오른쪽에서 방(부엌·다용도실·거실)을 고릅니다.
   - 다 고쳤으면 [tuner-state.js 저장]을 누르고, 저장된 tuner-state.js 파일로 이 폴더의 tuner-state.js 를 바꿔 넣으면
     게임에 반영됩니다. (바꾸기 전 원래 파일은 따로 복사해 두면 되돌리기 쉬워요)
   - 저장하지 않고 창을 닫거나 새로고침하면 고친 내용이 사라집니다.

폴더 안 파일·폴더 이름이나 위치를 바꾸면 그림이 안 나올 수 있어요. 폴더째로 두고 실행해 주세요.
예전 버전을 열어 본 크롬이라 옛 화면이 보이면, 페이지에서 Ctrl + Shift + R(맥: Cmd + Shift + R)로 새로고침해 주세요.
